## What I do

I build web experiences where design and function aren't separate conversations. A clean interface means nothing if the logic underneath breaks under real use — and solid logic means nothing if people can't move through it easily.

I work across the full picture: how something looks and feels, and how it holds up when real people use it every day, not just in a demo.

<br>

```
role        Web Developer
focus       Interfaces that feel effortless, systems that stay accurate
stack       React · Supabase · Tailwind CSS · PostgreSQL · Node.js
approach    Build for the user first — clarity, reliability, convenience
```

## Featured work

**Ark Industries — Workforce Management ERP**
A production HR/attendance system built in React + Supabase. Overtime logging, missed-timeout appeals, geofenced clock-in, per-date schedule resolution — the kind of logic that has to be exactly right because payroll depends on it.
`React` `Supabase` `PostgreSQL` `Tailwind`
