## What I do
I build web experiences where design and function aren't separate conversations — a clean interface means nothing if the logic underneath breaks under real use, and solid logic means nothing if people can't move through it easily. My focus is delivering both: interfaces that feel effortless, and systems that stay accurate and dependable behind the scenes.

I work across the full picture — from how something looks and feels, to how it holds up when real people are using it every day. The goal is always the same: make things convenient, make them work, make them worth using.
