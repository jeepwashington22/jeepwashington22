## What I do

I build the parts of a system that break quietly if you're not careful — attendance logic, overtime calculations, timeout detection, hour totals that have to match between what an employee sees and what an admin sees. Most of my work lives inside large, stateful React codebases where a single async race condition can throw off a whole day's data.

I'm not chasing trendy stacks. I'm chasing systems that hold up under real usage.
